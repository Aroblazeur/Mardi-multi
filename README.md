# Mardi Multi

Application autonome pour proposer des jeux et voter en groupe.

- Frontend statique dans `index.html`
- Backend séparé sur Supabase (`mardi-multi`)
- Vote simple par pseudo, sans compte
- Recherche Steam + ajout manuel
- Notes sous chaque jeu

Backend : `https://mwnhzfmayqvvlcyozrmk.supabase.co/functions/v1/mardi-multi`
